# personal_tools

Colección de pequeñas herramientas para tareas cotidianas. Cada una vive en su
propia carpeta, es autónoma y trae su propio `README`. Pensadas para usarse en
**Linux, Windows o Mac** y compartirse libremente.

## Herramientas

| Herramienta | Qué hace |
|---|---|
| [`dni-watermark`](dni-watermark/) | Pone una marca de agua a un DNI/documento y genera un PDF protegido, listo para enviar de forma segura. |

## Filosofía

- **Simples de usar**: línea de comandos clara y, cuando tiene sentido, modo interactivo.
- **Multiplataforma**: funcionan igual en Linux, Windows y Mac.
- **Con o sin Docker**: puedes instalarlas con Python o usarlas en un contenedor, sin instalar nada más.
- **Privadas por defecto**: procesan tus datos en local, sin enviarlos a ningún sitio.
